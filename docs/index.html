JobLens

A Chrome / Edge extension that checks how well a job listing matches your profile and preferences using your own AI API key (OpenAI, Anthropic, or Google Gemini).

Install in developer mode

JobLens is not on the Chrome Web Store. Install it unpacked from the latest GitHub Release:

  1. Open the latest Release
  2. Download the joblens-v*.zip asset (not “Source code”)
  3. Unzip it to a folder you will keep
  4. Open chrome://extensions (or edge://extensions), enable Developer mode, click Load unpacked, and select the unzipped folder (it should contain manifest.json)
  5. Open JobLens → Settings, add your AI API key, then run a check on a full job listing tab

Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

JobLens uses user data only to provide its single purpose—job compatibility checking and related features you initiate—and does not sell user data or use it for advertising or credit decisions.
