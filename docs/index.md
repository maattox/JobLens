# JobLens

JobLens is a Chrome / Edge extension that checks how well a job listing matches your profile and preferences using your own AI API key (OpenAI, Anthropic, or Google Gemini).

## Links

- [Privacy Policy (HTML)](https://maattox.github.io/JobLens/privacy.html)
- [Privacy Policy (Markdown)](privacy.md)

## Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

JobLens uses user data only to provide its single purpose—job compatibility checking and related features you initiate—and does not sell user data or use it for advertising or credit decisions.
